Topik di Luar Lingkup PUEBI
===========================

Halaman ini kosong sengaja. Topik "font bayi" dan generator font
dekoratif untuk media sosial berada di luar ruang lingkup Pedoman
Umum Ejaan Bahasa Indonesia (PUEBI).

Lihat bab **I.G Huruf Miring** dan **I.H Huruf Tebal** untuk
pembahasan tentang penggunaan variasi cetak dalam teks berbahasa
Indonesia.
