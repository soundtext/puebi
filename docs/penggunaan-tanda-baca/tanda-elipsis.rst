I. Tanda Elipsis (…)
====================

1. Tanda elipsis digunakan untuk menunjukkan bagian kalimat atau kutipan
   yang dihilangkan atau tidak disebutkan.

   Misalnya: Penyebab kemerosotan ... akan diteliti lebih lanjut.; ...,
   lain lubuk lain ikannya.

2. Tanda elipsis digunakan untuk menulis ujaran yang tidak selesai dalam
   dialog.

   Misalnya: "Menurut saya, ..., seperti .... Bagaimana, Bu?"

3. Tanda elipsis digunakan untuk menandai jeda panjang dalam tuturan yang
   dituliskan.

   Misalnya: Maju ... jalan!; Satu, dua, ... tiga!

4. Tanda elipsis di akhir kalimat diikuti tanda titik, tanda tanya, atau
   tanda seru.

   Misalnya: ... bahasa negara ialah ....; "... sebagai ...?"; "... jika
   kamu ...!"
